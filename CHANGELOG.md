# Changelog

Заметки о значимых решениях по поведению CLI, зависимостям и процессу проверки. Не привязан к номерам версий — проект не публикует релизы, это просто хронология решений.

## 2026-08-28

- **Защита CSV-экспорта от инъекции формул.** Поля из ответа GitHub API (`description`, `name` и др.) экранируются апострофом перед записью в CSV, если начинаются с `=`, `+`, `-` или `@` — иначе Excel/LibreOffice/Sheets могли бы исполнить их как формулу. JSON-экспорт не тронут: риск специфичен для табличных редакторов.
- **Валидация аргументов CLI.** `--limit` теперь ограничен 1–100 (справка и раньше это обещала, код — нет), `--min-stars` — только неотрицательные значения, `--output` — только `.csv`/`.json`. Некорректные значения завершаются понятной ошибкой до сетевого запроса.
- **Именованные константы.** `timeout` и fallback-запрос (`stars:>1000`) вынесены из тел функций в константы рядом с `API_URL`.
- **Тесты: 0 → 37.** Покрыты построение поискового запроса, CSV/JSON-экспорт (включая защиту от инъекции и граничный случай пустого списка), `fetch_repos()` через моки HTTP (успех, пустой ответ, HTTP-ошибка), полный CLI end-to-end через `main()`.
- **CI и защита ветки.** GitHub Actions гоняет `pytest` на каждый push/PR в `main`; `main` защищена ruleset'ом — слияние блокируется без зелёного check `test`.
- **`User-Agent`.** Контактная заглушка `example@example.com` заменена на реальный контакт.
- **`AGENTS.md`.** Добавлен единый вход для coding-агентов: структура проекта, порядок проверки, safe-change границы.
- **Hash-locked зависимости.** `requirements.txt` заменён на `requirements.in` (прямые зависимости) + `requirements.lock.txt` (полное резолвенное дерево из 12 пакетов с sha256-хешами, генерируется через `pip-compile --generate-hashes`). Установка воспроизводима и проверена hash-checking'ом.
- **Линтер мёртвого кода.** `ruff` подключён с правилами только pyflakes (`ruff.toml`) — ловит неиспользуемый код, не форматирование. Часть CI.
- **`Makefile`.** Единая точка входа для `install`/`test`/`lint`/`check`/`run`/`clean`.
- **Проверка уязвимостей по закреплённым версиям.** `pip-audit -r requirements.lock.txt` — известных уязвимостей не найдено ни в одном из 12 закреплённых пакетов (прямых и транзитивных).
